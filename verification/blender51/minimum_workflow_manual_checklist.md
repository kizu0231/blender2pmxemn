# Blender 5.1 最低限機能 実機確認チェックリスト

Blender 5.1 上で `blender2pmxemn` の最低限の機能が動くかを、UI から確認するためのチェックリストです。
headless 検証のあとに実行し、PR や issue に結果を転記しやすい形で使うことを想定しています。

## 事前準備

- Blender 5.1 を起動する
- このリポジトリの作業中アドオンが読み込まれるように `BLENDER_USER_SCRIPTS` を設定する
- サンプルとして `sample/default.pmx` を使う
- 必要に応じて `sample/sample.blend` を開けることを確認する

## 確認ケース

### 1. アドオン登録

- [ ] 「編集」→「プリファレンス」→「アドオン」で `blender2pmxemn` を有効化できる
- [ ] 有効化後にエラーが出ない
- [ ] 期待結果: チェックを入れると有効になり、Blender のステータスバーやシステムコンソールに例外が出ない

### 2. PMX インポート

- [ ] 「ファイル」→「インポート」から `PMX File for MMD (.pmx)` を選べる
- [ ] `sample/default.pmx` を読み込める
- [ ] 期待結果: アーマチュアとメッシュが作成され、読み込み直後に操作不能にならない

### 3. XML 作成

- [ ] PMX 読み込み後に XML 作成メニューを実行できる
- [ ] 期待結果: 対応する `.xml` が作成され、システムコンソールに致命的なエラーが出ない

### 4. PMX エクスポート

- [ ] 読み込んだモデルをそのまま `PMX File for MMD (.pmx)` で書き出せる
- [ ] 期待結果: 出力先に `.pmx` が作成され、処理完了まで例外が出ない

### 5. アーマチュアの雛形をアペンド

- [ ] 「アーマチュアの雛形をアペンド」を実行できる
- [ ] 「標準」を選べる
- [ ] 期待結果: アーマチュアが 1 つ追加され、ポーズモードへ入れる

### 6. 主要ボーンツール 1 ケース

- [ ] 追加したアーマチュアをポーズモードにする
- [ ] 適当なボーンを 1 本選ぶ
- [ ] 回転固定の切り替えを実行できる
- [ ] 期待結果: 選んだボーンの回転固定状態が変化し、操作後も選択状態が維持される

### 7. 余力があれば確認する補助ケース

- [ ] `Aポーズへ` を実行できる
- [ ] `Tポーズへ` を実行できる
- [ ] 期待結果: 少なくとも肩や腕の姿勢に変化が出て、実行前後で見た目かボーン値のどちらかに差がある

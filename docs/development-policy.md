# 開発方針

## 基本方針

- まずは既存機能を Blender 5.1 上で継続利用できる状態にします。
- 大きなリファクタや CI の再設計は、既存機能の安定化を優先したうえで段階的に進めます。
- 変更は小さく分けて管理します。

## 優先順位

### 第1優先: Blender 5.1 で最低限動かす

- アドオン有効化
- PMX import / export
- XML 作成と連携
- テンプレート追加
- 主要なボーン・ウェイト関連ツール

### 第2優先:export時の品質の改善

- モデル名の保持
- 剛体・ジョイント情報の保持
- 材質モーフの保持
- テクスチャの相対パス化とコピー

### 第3優先: 保守性の改善

- 大きなモジュールの整理
- Blender 5.x 互換処理の集約
- CI の改善
- `uv` の導入検討

## 補足

- 通常の改修は `develop` から feature ブランチを切って進めます。
